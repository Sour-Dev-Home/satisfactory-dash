- 2026-11-01 — Planner: the outline is virtualised (ADR-0062 Decision 3's rule: its measured render passed 50 ms on CI, up to 54.9 ms rendered and 102.8 ms painted). No library, and no row leaves the DOM once mounted, since the outline is the canvas's text path. Each group row gets `outline-row-lazy` (`content-visibility: auto` with a remembered size, estimate token `--spacing-outline-row-estimate`, visible in print), so the browser skips layout and paint off screen. The first render mounts only the first 24 rows and those around the current row (`mountsFirst`, `OUTLINE_FIRST_ROWS`, `OUTLINE_CURRENT_BEFORE` in `outlineModel.ts`), and a transition mounts the rest; a neighbour's button to a row not mounted yet waits for it. Measured on the dev box at 2x CPU throttle (which matched CI's before numbers): rendered 26 to 39 ms became 14 to 21, painted 67 to 87 became 28 to 46; all 160 rows are in the DOM by 53 to 89 ms. The e2e measurement now also records that time and the first frame's row count; full-page screenshots paint every row first (`paintLazyRows`), so no baseline should change. ADR-0062's "Values chosen in build PR 4 (outline)" has the numbers and the trade-offs.
