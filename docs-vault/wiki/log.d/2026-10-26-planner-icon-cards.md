- 2026-10-26 — Planner canvas cards are icon-first and compact (the owner's complaint that too much info was stuck to each node, and some had none): a group card is the building's icon (40 units, up from 18), a "×N" machine count and ONE line, its main product and rate ("Iron Plate · 48/min"); bubble, fold and factory cards follow (a factory card keeps its name and one product line, with its main machine's icon). The recipe, the other outputs, the share split, where a remote group stands, the storage chips and "In a loop" moved to the side panel (`GroupPanel`, which now lists them) and stay whole in the card's tooltip and its keyboard button's name, built from the same helpers (`Card.description`, `nodeFacts`). A class with no icon (or an icon that fails to load) draws a generic glyph for its kind (`buildingGlyphs.tsx`, `glyphKindOf`: machines, storage, extractor, station, power, consumer, unknown), never a bare box. Empty-card hunt: the scene and layout code never produced a card with neither text nor picture, but a group with a blank name had an empty tooltip, keyboard name and title, a blank recipe drew a blank line, and a NaN count could print "×NaN"; each now falls back (the class name, "Unknown building", "Unnamed factory", no badge), pinned by `canvasScene.empty.test.ts`. Card sizes are tied to the new shape (`cardLineY`, `countBadgeWidth` in `layoutSite.ts`); `layoutScene` stays deterministic.
