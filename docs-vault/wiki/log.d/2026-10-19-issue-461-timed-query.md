- 2026-10-19 — ADR-0037 build step 4 contract (#461): every repository and service query under `backend/src/modules/` and `backend/src/platform/` now runs through `timedQuery` (`platform/db/timedQuery.ts`, exported from `platform/db/index.ts`), which records `db.client.operation.duration` labelled only by a static query name. The name is the existing `parseRows`/`parseFirst`/`parseOne` context where there is one, or a new `<module>.<operation>` name otherwise. The registry's `QUERY_NAMES` is the closed list of names, and the label check is now one of those names instead of any bounded token. A source-scanning test fails on a direct `.query(` call outside the allowlist (the transaction helper, the readiness probe, the schema check, the admin bootstrap) and on any mismatch between the names the code passes and the names registered. SQL text, repository signatures and transaction behaviour are unchanged. The metrics flush's own writes are now timed too, so each flush records the previous one's database time.
