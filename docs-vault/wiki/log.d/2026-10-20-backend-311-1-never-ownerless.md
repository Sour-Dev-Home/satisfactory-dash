- 2026-10-20 — #311 task 1/3, a live server can never be left without an owner. Migration `1791244800000_members_never_ownerless.sql` adds a deferred constraint trigger on `servers.server_members` (DELETE, or UPDATE of `role` or `server_id`, so moving the owner row to another server is refused too): at commit, a live server with no owner row fails with `ownerless_server` (check violation, constraint `server_members_never_ownerless`). Deleting an owner's account is therefore refused until the server is transferred or deleted; `transferOwnership` and the soft delete keep working because the check waits for commit. `transferOwnership` maps the refusal to a typed `would_orphan` result. The startup seed now tags its audit row `source: 'startup_seed'` and logs one `ownership seeded` line per server (`loadDatabaseServers` returns `ownershipSeeded`). No user-facing change. DB tests in `neverOwnerless.db.test.ts`.
