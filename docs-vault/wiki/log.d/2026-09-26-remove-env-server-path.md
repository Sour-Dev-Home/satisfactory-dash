- 2026-09-26 — Backend (#196, architect ruling, option A): with a database (`DATABASE_URL`), the servers now come ONLY from it. Removed: the boot placeholder runtime built from the environment (`environmentServerEntries` in `platform/envServers.ts` builds nothing when a database is in use, so no poller can fire without credentials: the root of the #239 race), `registerConfiguredServers` (the module and its tests) with its precedence branch, and the "these server variables are ignored; remove them" warning. With a database and zero stored servers the backend serves none and logs ONE warning, by variable name only: "servers configured in the environment are not served when a database is used; run npm run admin -- import-servers" (still consistent with create's `import_required`). Kept: the environment loaders for `import-servers`, `captureFactory` and NO-DATABASE mode (dev, the demo, tests), which behave as before. Consequence: environment-configured LAN servers are no longer served in database mode (production has none; stored LAN servers wait for certificate pinning, ADR-0030 amendment 1). Runbook `servers.md` updated.
