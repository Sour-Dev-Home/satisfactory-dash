- 2026-10-24 — Supply-chain hardening, the rest of #561. `package.json` gains an `allowScripts` policy for the five
  locked packages with install scripts: esbuild and fsevents may run theirs, while ssh2, cpu-features (ssh2's
  optional native crypto binding, which has a pure-JS fallback) and protobufjs (only a version warning) are skipped.
  `.npmrc` sets `strict-allow-scripts`, so on npm 11.16+ an install fails when a new dependency brings an
  unreviewed script. Approve one with `npm approve-scripts --no-allow-scripts-pin <pkg>`, or deny it with
  `npm deny-scripts <pkg>`. Older npm (CI's Node 22) ignores the setting. compose.yaml's `postgres:18` is now
  pinned by digest, the same one staging runs. A new static test in `infra/aws/tests/` keeps the two equal, and the
  terraform workflow now also runs on compose.yaml changes. Dependabot's new `docker-compose` entry bumps both of
  compose.yaml's pins. The node base-image digests, CodeQL (default setup), image provenance, immutable migrations
  and SHA-pinned Actions were already done in #566 and #607.
