- 2026-10-16 — RDS automated-backup retention is now a Terraform variable (#418, ADR-0034): the owner's first `terraform apply` failed with `FreeTierRestrictionError` because the AWS Free plan refuses the hard-coded 7-day retention. New `db_backup_retention_days` in `infra/aws/variables.tf` (number, default 1, a whole number from 0 to 7; 0 turns automated backups off), used by `rds.tf`'s `backup_retention_period`. The nightly age-encrypted B2 backup (ADR-0035) stays the real backup; RDS automated backups are only the fast-restore extra. `tests/base.tftest.hcl` asserts the default 1 and adds runs refusing 8, -1 and 1.5 and accepting 0. `terraform.tfvars.example` shows the variable commented out, and `infra/aws/README.md` (the `rds.tf` row and a new Free plan fallback) and `runbooks/aws.md` (point-in-time restore) state the new retention and the 0 fallback. Nothing is applied.
