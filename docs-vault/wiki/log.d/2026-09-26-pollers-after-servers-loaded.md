- 2026-09-26 — Backend (#239): with a database, the servers' background workers (the power and factory history pollers, the observation feed) now start only AFTER the stored servers are loaded, not when the HTTP server starts listening. Before, the pollers of the placeholder runtime built from the environment fired first, went out without credentials, and logged "power/factory history poll failed; leaving a gap" with a 403 on every restart, leaving one missing history sample. The sequencing moved into `backend/src/platform/bootSequence.ts` (process workers at once; without a database the runtime at once; with one, the runtime and the database workers after the servers are loaded; nothing starts on a failure or a shutdown that began meanwhile), with tests that pin the order.
