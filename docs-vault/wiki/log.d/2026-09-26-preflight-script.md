- 2026-09-26 — Tooling (#287): `npm run preflight` (`scripts/preflight.mjs`, unit-tested in `scripts/preflight.test.mjs`, part of `npm run test:scripts`) is the check to run before every push. It fails when: the PR of the current branch is not OPEN or is CONFLICTING (via `gh pr view`; no PR yet is fine); the diff against `origin/main` (committed and uncommitted added lines) or the commit messages contain a local absolute path (the same shapes CI's PII scan rejects) or a line of the optional git-ignored file named by `PREFLIGHT_PATTERNS_FILE` (one fixed string per line; a match is reported by file and line, never by its text); or the worktree has no `node_modules`. This script and its test, and `LICENSE`, are exempt from the scan.
