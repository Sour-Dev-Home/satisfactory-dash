- 2026-10-28 — ADR-0062 amendment build PR 3, marching dashes and the in-view cap (frontend only, no contract change, no layout change, no new dependency). New `planner/graph/marching.ts`: `marchStep(flow)` says which lines march and at which `rateStep` (a belt or pipe line with a measured or estimated rate, "at least" counting as estimated, not stalled; unknown and stalled lines and transports stay still), `marchCandidates` lists them once per layout (fastest step first, then edge order) and `marchingLines` keeps those whose route's bounding box meets the view, up to `MARCH_MAX` (60). The view is the canvas's own pan and zoom, read once it has been still for `MARCH_SETTLE_MS` (150 ms, new `useSettled` hook), so a drag does no per-frame work. `SiteGraph`'s `EdgeLine` animates by class only: an estimated line's own dashes (`animate-flow-{step}`) and a mixed one's inner dashes in step (`animate-flow-inner-{step}`); a measured line stays solid and gets a thin `stroke-fg-strong` pulse path (`3 10`, `animate-flow-pulse-{step}`) whose opacity is 0 except while its animation runs, so a still frame, a screenshot with animations disabled and reduced motion draw today's line. `index.css` adds `--flow-dash-cycle` (13), `--flow-dash-inner-offset`, `--opacity-flow-pulse`, the nine `--animate-flow-*` tokens on `--duration-flow-*` and three keyframes that lower `stroke-dashoffset` toward the arrowhead, and under reduced motion `[data-march] { animation: none !important }`. Motion Off and a hidden tab render no class or pulse. The Motion control now shows whenever a transport or a marching line exists (it needed a transport before), so planner screenshots of canvases without transports gain it in the toolbar. New `planner-large` scenario (160 groups, 210 lines, from the shared fixtures) and an e2e test in `planner-graph.spec.ts` that checks the cap and Motion Off under the CSP and records `requestAnimationFrame` frame times (fitted, all in view, Motion Off) as an attachment; the ADR amendment's "Values chosen in build PR 3" leaves the box run's numbers and the cap's confirmation as a TODO.
