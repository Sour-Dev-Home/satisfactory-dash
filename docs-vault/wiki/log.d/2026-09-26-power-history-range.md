- 2026-09-26 — Frontend, ADR-0027 PR 8a (#74): the Power page's history gets a range picker (Live, 1 h, 6 h, 24 h, 7 d, 30 d, 1 y). Live is the unchanged 5-minute chart (ADR-0022); a stored range reads `GET /api/servers/:serverId/history/power?range=` and draws the bucket averages in the same uPlot chart, one per circuit of the newest game session (circuit ids change between sessions, so older sessions are counted, not shown). A missing bucket breaks the line instead of being interpolated, fuse trips are listed as stretches, and the readings table holds one row per bucket. `apiGetQuery` in `frontend/src/api/client.ts` validates a query string with the endpoint's `query` schema before sending, like a request body. The demo world serves its own stored history for every range, with a 2-hour gap.
