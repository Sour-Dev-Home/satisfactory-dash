- 2026-09-27 — Prototype-unsafe lookups are now a lint check, not a reviewer's memory (#368, the architect's spec; #361 and #367 both hit the bug class). oxlint has no `no-restricted-syntax`, so the two rules live in a local oxlint JS plugin, `scripts/lint/safe-lookup.mjs`, loaded by every package's `.oxlintrc.json`: `no-in-operator` (a variable `key in obj`; a literal key such as `"route" in value` is TypeScript's narrowing idiom and allowed by design) and `no-table-index` (`ALL_CAPS_TABLE[variable]`, unless it's the true branch of `Object.hasOwn(TABLE, key) ? ...` on the same table and key). The fix is Object.hasOwn, a Map, or the new `ownValue(table, key)` in `packages/shared`. PR 1 of 3: ERROR in shared and agent (no hits), WARN in backend, game-adapter and frontend until PRs 2 and 3 convert their hits. `scripts/lint/safe-lookup.test.mjs` runs the real oxlint on #361's and #367's old shapes (flagged) and the fixed forms (clean), which also guards the plugin against an oxlint bump (its JS-plugin API is alpha; noted in `.github/dependabot.yml`).
