- 2026-09-26 — Data age follow-up (the architect's note on #249): the "newer data is overdue" warning on Status, Power and Factory no longer comes from this PC's clock. A view's data is late when the envelope's `stale` is true (the backend's call) or when the latest refresh failed while the cached snapshot stays on screen (TanStack's `isRefetchError`, passed from each view to its panel as `refetchFailed`). The client clock drives only the "Updated N s ago" text (`dataAgeText`), so a skewed PC clock can't make fresh data look late. The panels no longer import `POLL_MS`.
