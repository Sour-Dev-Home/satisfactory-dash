- 2026-10-25 — ADR-0052 follow-up (race fix): `withLastGood` (`telemetry/services/lastGood.ts`) numbers its calls, and only an outcome from a call started after the last applied one changes what it remembers. So a slow older read finishing after a newer one can no longer replace the newer value, or mark it stale when the older call fails. Late-arrival tests were added for `LatestSnapshotStore.record` and `withLastGood`. They came from an earlier test pass that was never committed.
