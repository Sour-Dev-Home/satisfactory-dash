- 2026-10-27 — S4-A gate 2 (R7, agreed with the mod session): the agent snapshot body (`SnapshotRequestSchema` in `packages/shared/src/agent.ts`) gains three OPTIONAL sender-reported fields, `gameReachable` (could the sender read the game this cycle), `lastGameReadAt` (last successful game read, ISO datetime with an offset) and `modVersion` (the sender's version, mod or agent, 1 to 64 characters), so the server "test connection" can lose its FRM `getSessionInfo` half. They sit beside `reachable` rather than inside `status`, because `status` must be absent on an unreachable snapshot, which is exactly when these matter.
