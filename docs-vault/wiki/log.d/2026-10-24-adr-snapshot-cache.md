- 2026-10-24 — ADR-0052 (accepted): the dashboard keeps showing a server's last snapshot when its game is unreachable and after a backend restart. The envelope gains an optional `unreachableSince`, so an unreachable game serves its last parts stale (the banner stays, panels dim) instead of a 503; one row per server in `telemetry.latest_snapshots` holds only the latest status, power and factory (never player names), written at most every 5 minutes, on reachability changes and on shutdown, and loaded stale on startup. Two build PRs; the privacy page's player-count line is the owner's to confirm.
