- 2026-11-03 — The public pages are real HTML at build time (ADR-0021's 2026-11-03 build note, step 5's first part), after AdSense rejected the site for "ads on screens without publisher-content": `/` served an empty root and everything else is behind sign-in.
  - **Landing page.** `frontend/site/plugin.ts` prerenders it (`src/landing/prerender.tsx`, `renderToString` of `AppFrame` under `StaticRouter`) into `dist/landing.html`, which `main.tsx` hydrates. The Worker serves that file for exactly `/` and redirects `/landing` to `/`; `index.html` stays the empty shell for every app path. The footer reads the ads marker through `useSyncExternalStore` so hydration can't mismatch.
  - **Guides and changelog.** Markdown in `frontend/content/` (front matter `title`, `description`, `order`, `updated`), rendered by markdown-it (dev dependency, raw HTML off) into script-free pages at `/guides`, `/guides/<slug>` and `/changelog`, styled by `public/legal.css`. One placeholder guide, `getting-started`; the real guides come separately. The landing page links both (body and footer).
  - **Crawling.** `sitemap.xml` (every public page, not `/app`) and `robots.txt` (allow all). Both are excluded from the Worker in `wrangler.jsonc`; the new HTML pages go through it. None of it ships in the demo build. New raw source: `cloudflare-workers-html-handling-2026-11-03.md` (the whole `auto-trailing-slash` table).
