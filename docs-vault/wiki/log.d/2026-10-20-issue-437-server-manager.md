- 2026-10-20 — Server manager 1/4 (#437, ADR-0040): a new `server-manager/` npm workspace (`@satisfactory-dash/server-manager`), an Electron app for the owner's PC that starts and supervises the dedicated server. A pure supervisor (`src/supervisor.ts`: `stopped`/`starting`/`running`/`stopping`/`crashed`) spawns `FactoryServer.exe -log` with no shell, restarts an exit it didn't ask for at most 3 times in 10 minutes and then shows why it stopped; Stop just ends the process until the next task adds save-then-shutdown. Settings (server and SteamCMD folders) live in a zod-validated JSON file under `%LOCALAPPDATA%`, asked for on first run with a folder picker that refuses a folder without `FactoryServer.exe`. The window (sandboxed preload, a narrow typed bridge, a strict CSP, the dashboard's tokens generated from `frontend/src/index.css`) shows the state, uptime, CPU and memory, with `aria-disabled` Start, Stop and Restart. A Playwright suite drives the built app against a fake server (start, stop, restart, a crash that restarts, the back-off ending in `crashed`) and asserts the main process listens on no socket. The root scripts and CI's `verify` job now include the workspace.
