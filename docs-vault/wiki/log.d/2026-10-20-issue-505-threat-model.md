- 2026-10-20 — ADR-0045 (proposed, #505): a threat model for game servers the owner doesn't control, before the mod's first public release. One table per trust boundary (mod to backend, tunnel and edge, browser to backend, operator tooling) plus retention of other players' data; every risk is an existing control read in the code, a new task, or an explicit accept. New tasks: #514 (per-credential ingest budgets, and a global agent-auth limiter that can't lock out valid agents), #515 (per-server history and alert quotas, a fair outbox), #516 (disable an account, a server delete that also clears world layers and push opt-ins, an abuse runbook), and #517 (a design for self-serve agent servers, parked until sign-up opens). ADR-0042 gains a "See also" amendment.
