- 2026-09-26 — Backend: the request log line of `GET /api/health/ready` answering 503 (no error thrown) is now `warn`, not `error` (`requestLogLevel(status, err, url)` in `backend/src/platform/logLevel.ts`, called from `requestContext.ts`). The 503 is the expected answer while the process is still connecting to the database, so every deploy no longer shows a level-50 "request errored". Any other 503, and any thrown error, is still `error`.
