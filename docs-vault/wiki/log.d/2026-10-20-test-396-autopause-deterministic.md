- 2026-10-20 — The AutoPauseView ordering test (`AutoPauseView.races.test.tsx`) no longer orders the PUT and the late settings read with fixed MSW delays (40 ms / 120 ms), which under full-suite load could let the read start after the PUT had resolved (issue #396). Both handlers now wait on gates the test opens: the read starts while the PUT is held, the PUT answers first, then the read. The test then waits for that refetch to settle and asserts on the cache and the checkbox. Checked once with the view's post-PUT `cancelQueries` removed: the test fails.
