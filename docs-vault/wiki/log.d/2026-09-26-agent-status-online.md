- 2026-09-26 — Contract (ADR-0031, for the frontend's PR 7): `AgentStatusResponse` gains an optional `online: boolean` in `packages/shared/src/agent.ts`: true when the backend received a snapshot from this server's agent within the last 2 minutes, false when none did (including after a backend restart before the agent's next snapshot), absent when no agent is enrolled. It is computed server-side from the backend's in-memory record of the last snapshot (`observations.snapshot().agent.lastHeardAt`, handed to `createAgentsService` by the composition root), which is fresher than `lastSeenAt` (written at most every 30 s). The window is the new shared constant `AGENT_OFFLINE_DEFAULT_SECONDS` (120), which the `agent_offline` alert rule's default and preset now use as well, so the badge and the alert agree by default; a per-server override of that rule is not read, so they may differ at the margins. Additive and optional (an older backend omits it); no migration. Fixtures and tests updated.
