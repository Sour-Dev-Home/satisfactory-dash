- 2026-10-20 — TLS 1.2 floor for self-hosted backends (#493, owner decision): `npm run tls-floor -- set-cloudflare` raises a zone's Minimum TLS Version to 1.2 through the Cloudflare API (idempotent, never lowers, prints before and after), and `npm run tls-floor -- check <host>` fails unless the server refuses TLS 1.0 and 1.1 and accepts 1.2, treating a client that can't offer the old versions as inconclusive. `runbooks/compose.md` documents both; the official host passed the check. The backend has no TLS listener of its own, so the explicit `minVersion` rule applies to a future direct-TLS mode (#197).
