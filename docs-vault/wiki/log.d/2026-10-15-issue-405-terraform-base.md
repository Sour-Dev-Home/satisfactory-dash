- 2026-10-15 — Terraform part 1 for the AWS move (ADR-0034, #405). A VPC with two public subnets and an internet gateway, no NAT gateway; the task security group has `ingress = []`, the VPC's default group is emptied. RDS PostgreSQL 18 on db.t4g.micro, single-AZ, 20 GB gp3 with no autoscaling, encrypted, not publicly accessible, 7-day backups, deletion protection on (a variable for the exit), reachable on 5432 only from the task group, master password through `manage_master_user_password`. `ssm.tf` names 17 `/satis/prod/*` parameters by environment variable and outputs their ARNs, with no data source or resource, so no value reaches state. A monthly AWS budget on gross spend (credits excluded, since net spend is $0 on the Free plan) alerts at 80% actual and 100% forecast to an address set in the git-ignored `terraform.tfvars`. `README.md` has the owner's first-apply steps and the Free plan evidence (RDS, ECS and Budgets are on AWS's Free plan service list and db.t4g.micro PostgreSQL is on the RDS free plan page; no AWS page names Fargate ARM). Tests: `terraform test` with a mock provider (13 main, 3 bootstrap) and `tests/static.test.mjs`. `.gitignore` gains the Terraform state, plan, tfvars, backend and cache patterns.
