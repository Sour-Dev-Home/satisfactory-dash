- 2026-10-20 — #504: the CommandBar tests' flaky "Ctrl+K opens it". Each test mounts a new `CommandBar`, so its first open suspends on the lazy palette chunk, and React then holds the fallback for its fixed Suspense throttle (`FALLBACK_THROTTLE_MS`, 300 ms in React 19.3) before the search box appears. Measured: about 310 ms for every first open, plus about 90 ms of cold import for the file's first. That real wait sat inside `findByRole`'s 1 s default, leaving about 600 ms for rendering on a loaded machine. Every wait for the search box now goes through one `searchBox()` helper with a 3 s budget; what the tests assert is unchanged. Pre-loading the chunk was tried and made no difference, since the throttle, not the import, is most of the wait.
