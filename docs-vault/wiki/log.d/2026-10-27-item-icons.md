- 2026-10-27 — ADR-0060 build PR 1 (#726): item icons for the Planner. `scripts/dev/build-item-icons.mjs --src <dir>` converts the owner's FModel export of the game's item textures to WebP at 32, 64 and 128 px (`frontend/public/game-assets/items/<slug>-<size>.webp`) with the same pinned `sharp-cli@6.1.0` and settings as the building icons, run through `npm exec`, so no image library is added to the repo. `frontend/src/planner/graph/itemIcons.ts` maps 145 item classes to slugs; the class-to-texture pairs come from the game's own Docs file (`mPersistentBigIcon`, game 1.2.4.0), because texture names often differ from class names. `itemIconUrl(className, 32 | 64 | 128)` returns undefined on a miss, and `itemIconText(name)` gives the initials, or "?" with no name, so a bubble is never blank. Tests: every mapped class is a real item class (the backend's item-form catalog), every captured item class in `docs-vault/raw-sources` resolves except eight listed ones the export has no art for, every slug has all three files and no file is unmapped. `scripts/ci-select.mjs` now runs the frontend tests when raw-sources or that catalog change. The game-assets NOTICE covers `items/`. About 1.35 MB of WebP added under `public/` (32 px 0.15 MB, 64 px 0.35 MB, 128 px 0.84 MB), none in the JS bundle. No UI uses the icons yet (build PR 2).
