- 2026-10-25 — ADR-0055 PR 3 (ADR-0053 PR 3 without its site change): the planner graph now carries each edge's `flow` and `destination` and each node's `treeKey`, computed in a new pure module `telemetry/services/plannerFlows.ts` and wired into `productionGraph.ts`. **Flow** (ADR-0053 Decision 1): `supply` into a machine group that may use the item, or into a buffer (storage, station or `other` with an outgoing edge that may carry the item, not straight back to the source, so a tank on a producer's pipe is not a buffer); else `excess` when the source also supplies that item (null matches null), else `output`. Excess edges get the source's output minus its supply edges as an `estimated` rate when every supply edge has a number and it is the single excess edge for the item. `TERMINAL_RECIPES` stays empty: the AWESOME Sink is the recycler (owner, 2026-10-24). **Destination** (ADR-0055 Decision 3): `factory` for a machine group or a supply into a storage/station that reaches one over supply edges; `depot` for `Build_CentralStorage_C` (never a buffer); `sink` for `Build_ResourceSink_C`; `power` for a `Build_Generator*` consumer; `storage`, `export` (stations, routes not read yet), else `unknown`. The class comes from the snapshot or from the conveyor end id. **treeKey** (ADR-0053 Decision 3): union-find over same-recipe (kind, class, recipe) machine groups whose upstream supply closures share a machine group, passing through buffers and never entering raw sources (extractors, non-machines with no supply input); per recipe, starts in key order mark what they reach and stop at another start's mark, joining when that node is a machine or a buffer with a machine upstream. Non-machine bubbles: per site, kind, building class and items received. `tree|` plus the bubble's lowest group key. Nothing reads a rate, so rate-only changes leave flows and trees alone (tested), and output is byte-identical under shuffled input (tested). Sites, items (PR 4) and factories (PR 6b) unchanged.
