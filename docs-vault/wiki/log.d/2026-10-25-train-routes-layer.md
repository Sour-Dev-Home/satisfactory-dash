- 2026-10-25 — ADR-0055 PR 5: the `trainRoutes` world layer is live end to end. A new game-adapter mapper (`map/trainRoutesMapper.ts`, with lenient raw schemas `RawFrmTrainRouteStationSchema` / `RawFrmTrainRouteTrainSchema` in `rawSchemas.ts`) turns `getTrainStation` + `getTrains` into one flat array of `station` records (id, name, platforms with id, `load`/`unload` mode and item classes) and `train` records (id, name, timetable stop names in order, item classes across its wagons), sorted and amount-free so the hash is stable between reads. Station and stop names are kept exactly as the game wrote them (the 2026-10-21 capture has a trailing space, and a stop matches a station by that string). Everything is lenient: a record without id and name is dropped and counted, anything else missing or odd is trimmed to empty, and arrays are capped at the contract's limits. The adapter gains `getTrainRoutes()`; the agent's world reader and the backend's local poller read it every 10 minutes with the other world layers, hash-deduplicated; the existing ingest route and service already store any known layer under its cap (4,000 records), so they needed tests only. The planner does not use the layer yet (transport edges are PR 6a).
