- 2026-10-25 — Frontend: the signed-in `/app/pair` page for device-code pairing (ADR-0051 section 1, ADR-0057 D6). The person types the code (normalised to `XXXX-XXXX-XXXX`; a `?code=` is ignored and stripped, nothing is stored), confirms who is asking (server name as plain text, version, age), and approves it as a new server or as one of their own owner/admin servers (said plainly to replace its credential). Not found shows one message for every cause; 429 shows the wait; 403 is explained. "Open the dashboard" selects the paired server through router state. Linked from "Add your server"; the demo accepts one made-up code and 404s the rest. Mocks, scenarios and `states.spec` cases added; no contract change.
