- 2026-09-26 — Dependencies (the `cookie` part of Dependabot's group PR #295, which failed `verify`): backend `cookie` 0.7.2 to 2.0.1. Only the request side uses it: `parse` is now `parseCookie` (`identity/session.ts` and `identity/routes/googleAuth.ts`, imported under the same local name); `@types/cookie` is removed (2.x ships its own types; the 1.0.0 that Dependabot proposed is a deprecated stub). Set-Cookie output is unchanged byte for byte because Express builds it with its own `cookie` 0.7.2, which npm now nests under `express` (`npm ls cookie`); `identity/cookieParsing.test.ts` pins the exact attributes. Two behavior differences of the new parser, checked against both versions on 21 inputs and pinned in that test: a double-quoted value keeps its quotes (0.7 stripped them; our cookies are never quoted, so a quoted one is an unknown value that signs no one in) and the result is a null-prototype object (a `__proto__` cookie is now an own key, harmless: only fixed names are read). Duplicates (first wins), percent-decoding, malformed escapes, trimming and empty values behave as before. The esbuild bundle inlines the ESM-only package and stays self-contained.
