- 2026-10-25 — ADR-0055 PR 9 (contract and routes): Planner designations, a player's named sets of buildings. New `packages/shared/src/plannerDesignations.ts`: a designation (id, name 1 to 64 visible characters, mode `core`, 1 to 1000 members of `{ id|null, c, x, y }` in whole metres, timestamps), the create and update bodies, the list response with read-time match info (`matched`, `missing`, `claimedBy`) and the 409 overlap error shape. Four endpoints under `/api/servers/:serverId/planner/designations`, now served by `backend/src/modules/map/routes/designationRoutes.ts` (reads: any member; writes: the existing member-write guard). Additive error codes `designation_overlap` (with `error.other`) and `designation_cap`; `ApiFailure` can now carry `other`. New table `map.factory_designations` (migration `1792022400000_planner_designations`, expand-only, no user id stored; each write records a `planner.designation_*` audit event with ids and counts only) and a purge line for it on server removal. `designationRepository.ts` takes the server row `FOR NO KEY UPDATE` in each write transaction, so the cap of 50 and the overlap check cannot be raced by two writers. Matching (id, else exact class and position, else nearest of the class within 2 m; one-to-one; older designation wins) is a pure function in `map/services/designationMatching.ts`, run at read time against buildings that the composition root passes in through a port (`telemetry/services/designationBuildings.ts`), so `map` still does not import `telemetry`. With no snapshot every member is missing. The app's 100 KB JSON parser skips the two designation write paths, which parse with a 512 KB limit after the session and member guards. Not done here: the production-graph reduction honouring designations (the reduction groups machines by site and recipe, so fixing designated machines to a factory needs a change to the group key; follow-up).
