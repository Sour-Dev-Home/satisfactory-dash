- 2026-09-26 — Frontend motion pass (the owner's token rule, ADR-0032's "site-wide motion pass"). Motion tokens in the `@theme` block of `frontend/src/index.css`: `--ease-standard`, `--duration-fast/-base/-slow`, `--spacing-motion-rise`, and two animations, `animate-reveal` (a tab's page fades in when it opens; an alert's detail when expanded) and `animate-pop` (the bell and account dropdowns opening). Buttons and tabs ease their hover colours, and Tailwind's `transition-*` defaults use the tokens. Opacity and transform only, so no layout shift; nothing waits for an animation and there are no exit animations. `prefers-reduced-motion` is honoured in one place: every duration goes to 0. The e2e axe helper now waits for running animations to finish, since axe counts opacity in contrast. The tab-switch pop-in itself (skeletons, one reveal per view, prefetch, `staleTime`) stays with ADR-0032 PR 3, the owner's call.
