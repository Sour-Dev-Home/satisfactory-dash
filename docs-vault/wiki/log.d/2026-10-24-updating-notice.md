- 2026-10-24 — Frontend "updating" notice during a deploy gap (ADR-0054 D4). A read that gets no response, or a 502, 503, 504 or 530 that is not the API's own error envelope (a non-JSON page, or JSON that is not the envelope), is a deploy gap: `StatusBanners` says "The dashboard is updating, back in a moment." once, the cached data stays on screen, and `api/deployGap.ts` refetches the failed reads after 5, 10, 20, then every 30 s until the backend answers (any data or API error clears it). After 180 s the notice gives way to the old "Couldn't reach the dashboard backend." The API's own 503 (`upstream_unreachable`) still says "Game server unreachable." Other proxy pages (500, 404) keep the old wording. Tests: `errors`, `client`, `deployGap` (fake timers), `StatusBanners`, and the `deploy-gap` scenario in `states.spec.ts`. No contract change; the demo build never produces a gap.
