- 2026-09-26 — Accessible names on the Servers page (#305, from #302's ui-review). Every server row has the same buttons (Test connection, Edit or "Edit host", Re-enter both tokens, Rename, Remove), so a screen-reader user heard several identical "Remove" buttons. Each one's accessible name now carries its server ("Remove Friends' save", "Edit host of Friends' save"), starting with the visible text (WCAG 2.5.3). The visible labels are unchanged. It uses `aria-label`: visually hidden text lost its leading space in the name computation (jsdom gave "RenameCreative test world"). Tests find the buttons by their full names, plus a new test that the names are distinct.
