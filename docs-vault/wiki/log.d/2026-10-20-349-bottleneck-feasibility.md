- 2026-10-20 — Feasibility study for the bottleneck finder (#349), ADR-0048 (proposed). Belt-level root cause is a no-go on FRM data: `getBelts`/`getPipes` say only whether each end is connected, not to what, `getFactory` has no port positions, and no documented endpoint lists splitters or mergers. Item-level root cause is a go with data already in the factory snapshot: a bipartite machine/item graph and an upstream (or downstream) walk with ranked verdicts, O(V + E), no new reads or snapshot bytes. Also found: FRM reports one `ConsPercent` for all of a machine's ingredients, so the classifier's `missingInput` is a tie-break. Adds `wiki/proposals/349-issue-body.md`.
