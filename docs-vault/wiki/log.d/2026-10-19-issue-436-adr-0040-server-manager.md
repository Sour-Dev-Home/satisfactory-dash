- 2026-10-19 — ADR-0040 records the server manager (#436), approved by the owner on 2026-10-19: a small Electron app (a new `server-manager/` workspace, the owner's PC only, no installer, signing or auto-update) that replaces the one-line start script as a holdover until the mod (ADR-0039 G3). It starts the game server as a supervised child process with no shell, stops it with `SaveGame` then `Shutdown` through the HTTPS API and kills it only after a timeout, updates it through SteamCMD (app 1690800), restarts after a crash at most 3 times in 10 minutes, and watches the agent, which stays a Scheduled Task. It runs as the user, opens no port, never shows or logs a token, and keeps its settings under `%LOCALAPPDATA%`. The decisions README and `wiki/index.md` link it; the build tasks that follow define their own contracts.
