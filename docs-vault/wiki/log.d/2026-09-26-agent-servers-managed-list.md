- 2026-09-26 — Backend + contract (ADR-0031, architect card from the #263 review): servers reached through an edge agent no longer vanish from the operator's management. Enrolling deletes the server's stored connection, and the managed list and rename were keyed on connections, so an agent server could be neither listed nor renamed. Additive contract in `packages/shared/src/serverManagement.ts`: `ManagedServerListResponse` gains an optional `agentServers` (`{ id, displayName, kind: "agent" }`, no connection fields), and a new endpoint `PATCH /api/servers/:serverId/name` (`serverManagement.renameAgent`, operator only, `{ displayName }` to `{ server }`) renames one; a `local` or unknown id is the same not-found (a local server is still renamed through `PATCH /api/servers/:serverId`). `ServerManagementService` gains `listAgentServers` and `renameAgentServer` (no secrets key needed, no connection test). Invariant: `ServerRuntime.replace` refuses to replace an agent entry (`kind: "agent"`, set by `buildAgentServer`) with a polled one and throws `AgentRuntimeReplacedError` before anything changes, so a future path cannot silently drop an agent's runtime and its `online` state; enrolling (polled to agent) and remove-then-add stay allowed. Also `EnrollmentCodeResponse` is exported as a type from shared (architect's #262 card), and a Windows line-ending fragility in the #153 ordering test was fixed.
