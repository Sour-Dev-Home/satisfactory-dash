- 2026-09-25 — ADR-0027 amendment 2, the clock speed contract: `FactoryBuilding` gains an optional `clockSpeedPercent` (FRM's `ManuSpeed`, the configured speed in percent; 100 is the default clock and it exceeds 100 when overclocked with power shards, `docs-vault/raw-sources/frm-getFactory.md:54`), additive and optional so an older backend's responses still parse (ADR-0007). Evidence: the committed 2026-09-22 running capture has six machines at 100 and one at 160. Backend: `rawSchemas.ts` reads `ManuSpeed` as an optional number that is tolerant (a value that is not a finite number, such as JSON `1e999`, becomes undefined instead of rejecting the whole factory response), the adapter maps it and omits it when absent, not finite or not above 0 (a clock of 0 or less is not a meaningful setting; no upper bound, for mods; the shared schema stays unconstrained so an odd value can never fail a whole factory response; the architect's call), and `ProductionService` passes it through. Fixtures: the captured backed-up assembler carries 100 and the 160 percent stator carries 160. Tests: the adapter mapping (100, 50, 160, a fraction, absent, null, string, object, NaN, both infinities, other buildings undisturbed), the service passthrough and the shared schema. The frontend shows it in a follow-up; a 50 percent machine joins the new state fixture once that lands.
