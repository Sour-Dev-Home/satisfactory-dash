- 2026-10-20 — Server manager 2/4 (#438, ADR-0040): Stop is now the clean stop. The supervisor reads the current session from `QueryServerState`, calls `SaveGame` with it and then `Shutdown` through the dedicated server's own API (`server-manager/src/gameApi.ts`, over the game-adapter's `VanillaApiClient`; the `SaveGame` and `Shutdown` request shapes are marked [NEEDS VERIFICATION]), and ends the process if it is still there 60 s after `Shutdown`, saying "Stopped without a clean shutdown". The API token comes from the agent's own DPAPI store (`src/gameAccess.ts`; `@satisfactory-dash/agent` now exports `AgentStore`, `resolveDataDir` and `createDpapi` from a new `agent/src/index.ts`, with no change to the agent's behaviour) and goes only into the request: errors are redacted, and a test pins the window's bridge, channels and status fields so none can carry it. With no token stored, or when saving fails, nothing is stopped and the window offers "Stop anyway" (or "Restart anyway"). Update (`src/updater.ts`) stops a running server cleanly after a confirmation, runs the configured `steamcmd.exe +force_install_dir <server folder> +login anonymous +app_update 1690800 validate +quit` with no shell, streams its output into the window, reports success or the exit code and offers to start the server; Start, Stop and the folders wait while it runs. Playwright drives Update against a fake SteamCMD (success, a non-zero exit, and the running-server path), and the e2e app now reads an empty agent folder, never the real one.
