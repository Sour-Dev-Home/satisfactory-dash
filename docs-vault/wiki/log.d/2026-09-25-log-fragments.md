- 2026-09-25 — ADR-0033 B, log fragments. `log.md` is frozen (a header says so) and every PR from now on adds one file `docs-vault/wiki/log.d/<YYYY-MM-DD>-<branch-slug>.md` with one or more bullets in log.md's style, so two PRs never edit the same lines. `scripts/log.mjs` (`npm run log`) prints log.md and then the fragments in file-name order; `npm run log -- --compact` folds the fragments into log.md and deletes them (the coordinator's own PR, labelled `log-compaction`). `scripts/log-check.mjs` runs in the `verify` job on `pull_request` events only: the PR must add at least one well-named fragment and must not modify or remove `log.md` or an existing fragment; the label `log-compaction` and the Dependabot author are exempt, and the errors say exactly what to do. Labels are read live from the API, so a re-run after adding the label works. This PR itself edits log.md (the freeze header), so it carries the `log-compaction` label. References updated: the root `CLAUDE.md`, `index.md` and `decisions/README.md`. `WORKFLOW.md` (outside this repo) needs the same update by the coordinator, and in-flight PRs move their `log.md` line into a fragment.
