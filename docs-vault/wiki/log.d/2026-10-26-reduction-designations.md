- 2026-10-26 — ADR-0055 Decision 5 (closes #692): the Planner's factory reduction honours designations. The production-graph route matches the stored designations against the snapshot (`matchDesignations`, via `BottlenecksRouteDeps.designations`; any read failure builds the graph as before) and passes a building-id to designation map to `buildProductionGraphWithStats`. The designation id joins the machine group key, so a group splits along a designation. In `factoryReduction.ts` designated machine nodes are always seeds, one factory per designation (key `factory|designation|<id>`, name and `designationId` from the designation, sorted first so the factory cap never drops it), left out of the same-product union and the small-factory fold, so they are never reassigned; shared upstream is still attributed to them by share. Without designations the output is unchanged. A designated factory lists as products only what leaves it: a seed whose product feeds only machines of the same designation is an intermediate.
