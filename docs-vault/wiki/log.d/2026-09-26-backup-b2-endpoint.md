- 2026-09-26 — ADR-0035 PR: the nightly backup gains B2 support. New optional `BACKUP_S3_ENDPOINT` (`backend/src/platform/backup/backup.ts`, `.env.example`): empty means plain AWS S3 with exactly the same `aws s3 cp` arguments as before; set, it must be an `https://` URL with no credentials, is reduced to its origin, and is passed as `--endpoint-url` after the profile. A refusal names the variable but never echoes the value. `runbooks/backups.md` gains the Backblaze section: the owner's account, bucket (Object Lock at creation, Governance 30 days), lifecycle (hide at 30 days, delete hidden after 7), the upload-only and read-only application keys, the `satis-backup-b2` profile, and the cutover (manual run, restore rehearsal from B2, switch the task, then two tiny privacy PRs: one adding the Backblaze row while keeping AWS's, one removing AWS's once the S3 bucket is deleted after 37 days read-only). The privacy page is NOT changed here: it describes only what runs today, and the nightly job still uploads to AWS S3 until the owner switches it. Tests cover the unset, valid and refused endpoint cases and the argument order.
