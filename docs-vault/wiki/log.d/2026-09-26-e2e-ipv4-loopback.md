- 2026-09-26 — Local e2e runs on Windows (#283, a self-report fix, top priority per the owner). The cause of "Timed out waiting 180000ms from config.webServer" wasn't a sandbox (Claude Code's Bash sandbox doesn't run on native Windows, and none is configured) or the build (3 s): `vite preview` resolved `localhost` to IPv6 and listened on `::1` only, Playwright's readiness check was refused there (`connect EACCES ::1:4173`), and its IPv4 fallback found nothing (`ECONNREFUSED 127.0.0.1:4173`). Both Playwright configs now pin one address, `127.0.0.1`, for the preview servers (`--host`) and every URL. With the owner's OK (two runs on :4173/:4174), `npx playwright test e2e/tab-switch.spec.ts` went from a 183 s timeout to 12 passed in 21 s. No change on CI, whose Linux resolves localhost to 127.0.0.1.
