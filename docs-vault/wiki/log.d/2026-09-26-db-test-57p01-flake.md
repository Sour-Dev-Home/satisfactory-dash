- 2026-09-26 — Test harness (#270): fixed the backend DB-test flake "FATAL 57P01 terminating connection due to administrator command" that failed a run although every test passed (and bounced #263 out of the merge queue). Cause: a DB test file's teardown drops its database with `DROP DATABASE ... WITH (FORCE)` (and the global teardown stops the container), so Postgres terminates every connection still open; each idle client of a raw `pg.Pool` the tests create emitted an `error` event, and a Pool with no listener makes that an unhandled error (the production pool has a listener; about 25 test files' pools did not). New `backend/test-support/pgIdleErrors.ts`, wired as `setupFiles` in `backend/vitest.config.ts`, gives every `pg.Pool` and `pg.Client` a test creates an `error` listener (applied once per worker): the shutdown codes 57P01 and 57P02 are silent, any other idle-connection error is printed by CODE only (never the message, which can quote a connection URL) so a real problem stays visible without crashing the run. Test: `test-support/pgIdleErrors.test.ts` (no database needed: emits the error on a pool and a client, once-only application, the patched classes are still the real ones, and a control showing an unhandled `error` throws).
