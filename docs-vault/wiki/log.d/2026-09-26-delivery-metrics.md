- 2026-09-26 — Tooling (#280): `npm run delivery-metrics` (`scripts/delivery-metrics.mjs`, unit-tested in `scripts/delivery-metrics.test.mjs`, part of `npm run test:scripts`) computes DORA-style delivery metrics from the GitHub API (merged PRs with their merge-queue events via GraphQL, CI runs on push to main via `gh run list`) and the `log.d` fragments: merged PRs per day and week, lead time (median, p90, mean of PR opened to merged), median change size, merge-queue bounce rate with removals by reason, failed CI runs on main and revert PRs as change-failure proxies, and the number of log fragments. It outputs a stable, versioned JSON (`schemaVersion` 1, aggregates only) and a markdown summary derived from it (`--json`, `--out <dir>`). A test asserts that no author, login, email, name, title, branch or body reaches the output, in keys or values. `runbooks/delivery-metrics.md` documents the shape and the definitions. It is the data source for the later metrics page (#281).
