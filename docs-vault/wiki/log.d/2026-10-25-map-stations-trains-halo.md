- 2026-10-25 — Follow-up to the live trains layer (#354, #666), from its ui-reviewer notes. A station no longer looks like the backed-up amber state: `--color-station` moves from yellow (#f2c14e) to pink (#f472b6, 6.7:1 against the canvas), and a station is now a diamond ring (an `L.polygon` on the shared canvas, rebuilt at a fixed pixel size on `zoomend`) instead of a circle; the legend matches. Each train dot gets a 2 px outline in `--color-canvas`, so dots stay apart in busy clusters. Trains were already on by default like rails (`defaultVisible: true`; off means no request, on again reads again, both covered by existing `MapPanel` tests), so nothing changed there. The ~1 s slide from stale positions after toggling the layer off and on is left as is: the remembered positions are shared with the redraw on every poll, so a reset needs a signal from the toggle, which is more than a one-liner.
