- 2026-11-11 — ADR-0066 leftovers: two things direct polling left behind, and the landing page's "How it's built" line. No contract change (`packages/shared` untouched), no migration.
  - Backend: the always-zero game-server timing is gone. Since PR 7 removed the adapter nothing called `recordUpstreamCall`, so `platform/requestTiming.ts` drops it with its AsyncLocalStorage store, `UpstreamInterval`, `unionMs`, `summarize` and `MAX_STORED_CALLS`. `Server-Timing` is now just `app;dur=<ms>` (the request's wall time; `upstream;dur=0` is no longer sent), and the request log line carries `appMs` only (`upstreamMs`, `vanillaMs`, `frmMs` and `upstreamCalls` are gone). `TimingSummary` is `{ totalMs }`, which `http.server.request.duration` (ADR-0037) still reads. `requestTiming.test.ts` checks the header shape and that the old log fields are absent.
  - `npm run latency-report`: the per-route upstream columns and the per-game-server-API table are gone, and the JSON has no `upstreams`. Older log lines that still carry the retired fields are read for their `appMs`, and the rest ignored. The fixture log and `latency-report.test.mjs` follow.
  - `backend/servers.example.json` is deleted: nothing has read it since `SATISFACTORY_SERVERS_FILE` was retired (PR 5). `.gitignore` and `backend/Dockerfile.dockerignore` keep ignoring `backend/servers.json` so a leftover copy with tokens is never committed or baked into an image; the `.gitignore` comment says so.

  - Docs: `runbooks/agents.md` no longer says the request log carries `upstreamMs`.
