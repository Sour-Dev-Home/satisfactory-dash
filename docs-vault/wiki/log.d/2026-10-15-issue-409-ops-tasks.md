- 2026-10-15 — Terraform part 3 for the AWS move (ADR-0034, #409): the ops image's jobs as ECS tasks inside the VPC, the nightly backup schedule and the AWS runbook. New `infra/aws/ops.tf`: four Fargate ARM64 task definitions (0.25 vCPU / 512 MB, container `ops`, image `var.ops_image` by digest, logs in the new 14-day `/ecs/satis-prod/ops`): `db-init` (a `sh` wrapper builds `DATABASE_ADMIN_URL` from the RDS master password, URL-encoded by node, then drops the password and runs `db:init`), `db-migrate`, `backup` (the compose service's command, with the B2 upload key handed to the AWS CLI from the `B2_*` SSM values) and `restore` (downloads `RESTORE_FILE` from B2 with a per-run read key, decrypts it with a per-run age key and runs `pg_restore --no-owner --single-transaction` as `satis_migrator`). The age private key and the B2 read key live under `/satis/restore/` only for one run: the owner puts them in and deletes them (decision D5); Terraform names them and never holds a value. New `ops_iam.tf`: one execution role per task reading only its own values; only `db-init` may read the RDS master secret (decision D4); no task role; and the Scheduler's role, which may run only the backup task definition in the cluster and pass only its execution role. New `schedule.tf`: EventBridge Scheduler runs the backup daily at 09:00 UTC (after the RDS backup and maintenance windows). `ssm.tf` gains `DB_BACKUP_PASSWORD`, `MIGRATOR_DATABASE_URL` and `BACKUP_DATABASE_URL`; `variables.tf` gains `ops_image`, `backup_b2`, `backup_schedule` and `backup_heartbeat_enabled`; three new outputs. Tests: `tests/ops.tftest.hcl` (9 runs), new static checks (only the ops files touch Secrets Manager, no permanent age key, the restore's key prefix equals `backup.ts`'s, the runbook's sections), and the restore and db-init scripts run for real against stub `aws`, `age`, `pg_restore` and `npm`. The static check that no tf file names `AWS_ACCESS_KEY_ID` now allows exactly the four B2-key mappings. New `docs-vault/wiki/runbooks/aws.md`: apply, deploy, migrate, restore, scale to 0, the monthly `aws freetier get-account-plan-state` check, and checking that the RDS master role can grant `satis_backup` `pg_read_all_data`.
